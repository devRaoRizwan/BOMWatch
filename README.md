# BOMWatch

Connect a GitHub account, pick repos, get an AI Bill of Materials
(CycloneDX format) for each one — dependency and AI-model usage inventory,
generated by a scan that runs on your own GitHub Actions minutes, not on
someone else's servers.

## Why this exists

Built as a portfolio project extending real production experience: CI/CD
pipelines where a security/dependency scan gates a release before it ships.
This applies the same pattern — scan as a pipeline stage, not an afterthought
— to a self-serve product anyone can connect their GitHub account to.

## How it works

1. Sign up, connect your GitHub account (via a GitHub App install)
2. Pick which repos to scan — some, or all
3. BOMWatch opens a PR adding a small workflow file to each selected repo
4. Once merged, the workflow runs on GitHub's own runners, using your
   Actions minutes — your source code never leaves GitHub's infrastructure
5. The workflow generates a CycloneDX AI-BOM and uploads it as a build artifact
6. BOMWatch pulls that artifact, parses it, and shows you the results

Free trial: a limited number of repos can be connected per account.

## Architecture

```
User → BOMWatch (FastAPI + React) → GitHub App install
                                    → PR: adds .github/workflows/bomwatch-scan.yml
                                          ↓
                                   GitHub Actions runs the scan
                                   (composite Action, published separately)
                                          ↓
                                   Uploads CycloneDX JSON as artifact
                                          ↓
                        workflow_run webhook → BOMWatch fetches artifact
                                          ↓
                              Parsed + stored in Postgres
                                          ↓
                                 Shown in the dashboard
```

Full architecture decisions and rationale live in [`CLAUDE.md`](./CLAUDE.md).

## Stack

| Layer | Choice |
|---|---|
| Backend | FastAPI, SQLAlchemy, PostgreSQL |
| Auth | JWT |
| Frontend | React (Vite) |
| Scan execution | GitHub Actions (composite Action, published separately) |
| DB hosting | Supabase (free tier) |
| Backend hosting | Render (free tier) |
| Frontend hosting | Vercel (free tier) |

## Local development

```bash
cd backend
cp .env.example .env      # fill in DATABASE_URL and JWT_SECRET_KEY
pip install -r requirements.txt
uvicorn app.main:app --reload
```

API docs available at `http://localhost:8000/docs` once running.
